# BUG-004: DELETE /booking/:id returns 201 Created instead of 200/204

- **Status:** Open (verify and attach your own response before publishing)
- **Severity:** Minor
- **Environment:** https://restful-booker.herokuapp.com, tested with curl / Postman

## Steps to reproduce
1. Create a booking and get a token.
2. Run:
```
curl -i -X DELETE https://restful-booker.herokuapp.com/booking/<ID> -H "Cookie: token=<TOKEN>"
```

## Expected result
200 OK or 204 No Content.

## Actual result
201 Created, a status meant for resource creation, with body "Created".
