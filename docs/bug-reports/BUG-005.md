# BUG-005: DELETE on a non-existent booking returns 405 instead of 404

- **Status:** Open (verify and attach your own response before publishing)
- **Severity:** Minor
- **Environment:** https://restful-booker.herokuapp.com, tested with curl / Postman

## Steps to reproduce
1. Get a token via POST /auth.
2. Run:
```
curl -i -X DELETE https://restful-booker.herokuapp.com/booking/999999999 -H "Cookie: token=<TOKEN>"
```

## Expected result
404 Not Found.

## Actual result
405 Method Not Allowed.
