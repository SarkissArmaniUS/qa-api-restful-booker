# BUG-002: POST /auth with wrong credentials returns 200 OK

- **Status:** Open (verify and attach your own response before publishing)
- **Severity:** Major
- **Environment:** https://restful-booker.herokuapp.com, tested with curl / Postman

## Steps to reproduce
1. Run:
```
curl -i -X POST https://restful-booker.herokuapp.com/auth -H "Content-Type: application/json" -d '{"username":"admin","password":"wrong"}'
```

## Expected result
401 Unauthorized.

## Actual result
200 OK with body {"reason":"Bad credentials"}. Clients checking only the status code may treat the login as successful.
