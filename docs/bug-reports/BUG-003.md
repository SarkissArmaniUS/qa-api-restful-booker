# BUG-003: PUT on a non-existent booking returns 405 instead of 404

- **Status:** Open (verify and attach your own response before publishing)
- **Severity:** Minor
- **Environment:** https://restful-booker.herokuapp.com, tested with curl / Postman

## Steps to reproduce
1. Get a token via POST /auth.
2. Run:
```
curl -i -X PUT https://restful-booker.herokuapp.com/booking/999999999 -H "Content-Type: application/json" -H "Accept: application/json" -H "Cookie: token=<TOKEN>" -d '{"firstname":"x","lastname":"y","totalprice":1,"depositpaid":true,"bookingdates":{"checkin":"2026-12-01","checkout":"2026-12-02"}}'
```

## Expected result
404 Not Found, because the resource does not exist.

## Actual result
405 Method Not Allowed, which wrongly suggests PUT is unsupported on this endpoint.
